# Common Password Checker

A simple command-line tool written in Python that checks whether a password appears in a list of common passwords. If your password is in the list, it's flagged as **common** — meaning it's unsafe and easy to guess.

## Modules used in the code

- os
- sys

## Requirements

- Python 3.6 or higher

## How to Run

1. Download or clone this project.
2. Make sure `passwords.txt` exists in the **same folder** as `check.py`.
3. Open a terminal in the project folder.
4. Run the script:

```bash
python main.py
```
